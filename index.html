Use -> or →, | for alternatives, ε or epsilon for empty. Names like id, E' are single symbols. Separate other symbols with spaces (a b, not ab). A nonterminal is any symbol on a left-hand side.

Examples

Concepts

CFG: a set of rules A -> α describing a language. Nonterminals (left-hand sides) get rewritten; terminals are the actual tokens. ε means "nothing".

FIRST(α): terminals that can begin a string derived from α (plus ε if α can vanish). FOLLOW(A): terminals that can appear right after A in some derivation; $ marks end of input.

Left recursion (A -> A α) makes a top-down parser expand A forever. It is removed by rewriting to A -> β A', A' -> α A' | ε. Left factoring rewrites S -> a b | a c into S -> a S', S' -> b | c so one lookahead can decide.

LL(1) table: for each A -> α, put it in M[A, a] for every a in FIRST(α); if ε is in FIRST(α), also for every b in FOLLOW(A). Two productions in one cell is an LL(1) conflict. The grammar may still be valid; it just needs transformation.

Predictive parsing: keep a stack starting with $ Start. Match terminals, expand nonterminals through the table, accept on $ vs $.
